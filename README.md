**本地优先、完全离线的手绘白板**。桌面端由 Tauri 2 承载，画布使用 leafer-ui 渲染；项目数据与 AI 自定义工具全部存在你自己的磁盘上（可自定义目录），不依赖任何云服务。

![Miniboard 主界面](docs/screenshots/miniboard.png)

## ✨ 特性

- **绘图工具**：画笔（压力敏感手绘笔迹）、直线、箭头、矩形、椭圆、文本、框架、橡皮擦（笔迹分段擦除）、框选、套索等，工具栏由统一功能注册表驱动
- **编辑操作**：重复（Ctrl+D）、删除等便捷编辑操作
- **AI 助手**（OpenAI 兼容接口）：交流模式感知画布内容、编辑模式让 AI 运行时创建自定义绘制工具（冒烟测试防护），支持多模态截图
- **整理与美化**：手绘形状一键识别为标准图形、标准图形一键转手绘风格（rough.js，seed 可复现，粗糙度 0–2 可调）
- **文本排版**：对齐 / 字体 / 字重滑条（100–900），`Ctrl+B` 快捷切换常规与加粗
- **箭头端点样式**：直线 / 箭头两端可独立设置箭头、三角、圆点、圆等端点
- **框架元素**：`F` 键创建虚线框（类 Figma Frame），框内元素跟随整体移动；支持导入 MD / 代码 / 文本文件为内容框架（按内容自适应尺寸，超高内容可折叠滚动查看）；支持聚焦框架（视口放大到框架）；拖入文件自动分流——图片直插画布、PDF 首页转图片、文本 / 代码生成内容框架
- **多项目管理**：独立画布 + 自动保存，启动自动恢复上次项目
- **可自定义数据目录**：项目与 AI 工具存储在本地文件（默认系统应用数据目录，可更改并自动迁移）
- **导出**：PNG 位图 / SVG 矢量图 / PDF 文档，元素结构无损

完整功能清单见下方 [功能细节](#-功能细节)。

## 🚀 安装

**方式一：直接下载**（推荐）
- 从 [Releases](../../releases) 下载 Windows 安装包（NSIS）或便携 exe
- 双击安装即可使用，无需任何配置

**方式二：源码构建**
1. 安装 [Rust](https://www.rust-lang.org/tools/install) 与 [Node.js](https://nodejs.org/)（≥ 18）
2. Windows 构建桌面版还需 [MSVC 工具链与 Windows SDK](https://learn.microsoft.com/zh-cn/windows/msvc/building-on-the-command-line)（推荐 Visual Studio Build Tools）
3. 克隆仓库后执行：

```bash
npm install
npm run tauri build        # 或 Windows：powershell -ExecutionPolicy Bypass -File tools/build-tauri.ps1
```

产物位于 `src-tauri/target/release/`。

## 🖥️ 快速开始（开发调试）

开发阶段推荐直接在浏览器中调试，无需构建 exe（浏览器功能与桌面端一致）：

```bash
npm install
npm run dev        # 浏览器打开 http://localhost:5173
```

需要验证桌面集成（文件对话框、系统存储等）时再运行 `npm run tauri dev`。

## 🤖 AI 助手配置

AI 助手使用 OpenAI 兼容接口（支持本地 Ollama / vLLM / 各种中转服务）：

1. 打开 ⚙ 设置 → **AI 模型** 页签
2. 点击「新建配置」，填写：
   - **名称**：任意，如 `Ollama`
   - **接口地址**：如 `http://localhost:11434/v1`
   - **API Key**：本地服务的 Key 可任意填写；中转服务填真实 Key
   - **模型名**：如 `qwen2.5:7b`（可点选「自动获取模型列表」）
   - **多模态**：开启后交流模式随消息附带画布截图（需模型支持视觉）
3. 点击「测试连接」验证，点选激活后即可使用

> **隐私说明**：API Key 与模型配置仅保存在本地；对话内容只会发送到你**自己填写的接口地址**，应用本身不收集任何数据。
>
> **安全提示**：API Key 以明文形式保存在 WebView 的 localStorage（磁盘上位于应用数据目录 `EBWebView` 下），未做额外加密。请勿在共用电脑上保存敏感 Key；如有更高要求，建议使用本地服务（如 Ollama）无需填写真实 Key。

## 💾 数据存储

| 数据 | 默认位置 | 说明 |
| --- | --- | --- |
| 项目画布 | `%APPDATA%\com.miniboard.app\projects\` | 项目索引 `index.json` + 每项目场景文件 |
| AI 自定义工具 | `%APPDATA%\com.miniboard.app\custom-tools.json` | AI 生成的绘制工具定义 |
| 界面偏好 / AI 配置 | WebView2 localStorage（同目录 `EBWebView` 下） | 主题、工具栏布局、模型配置等 |

- **更改目录**：⚙ 设置 → **数据** 页签 → 「更改目录…」，旧数据自动迁移到新目录，重启后自动恢复
- **备份**：直接复制数据目录即可（关闭应用后进行）
- 浏览器调试时数据存 localStorage，不占用磁盘目录

## 🧱 技术栈

| 层 | 技术 |
| --- | --- |
| 桌面壳 | Tauri 2（Rust） |
| 前端构建 | Vite 6 + TypeScript |
| 画布渲染 | leafer-ui 2.2.9 + @leafer-in/editor / arrow / export / text-editor |
| 笔迹轮廓 | perfect-freehand（压力敏感笔迹平滑与轮廓生成） |
| 手绘外观 | roughjs（标准图形 → 手绘风格路径，seed 可复现） |
| AI 助手 | OpenAI 兼容接口（SSE 流式）：浏览器直接 fetch，桌面端经 @tauri-apps/plugin-http 转发 |

```
│   ├── client.ts     # OpenAI 兼容客户端（SSE 流式 / 超时与取消 / 模型列表 / 连接测试）
│   ├── config.ts     # AI 多配置存储（localStorage，旧版单配置自动迁移）
│   ├── prompts.ts    # 双模式系统提示词
│   ├── tools.ts      # 画布感知 / 形状识别 / 工具执行器（update_elements 字段白名单、create_elements 官方格式解析）
│   └── types.ts
├── main.ts            # 入口：工具栏/状态栏/快捷键/右键菜单接线
├── storage.ts         # 存储层：多项目管理（项目索引 + 独立场景 + 旧数据迁移 + 数据目录可配置）/ 打开 / 另存 / 导出 PNG 与 SVG
├── types.ts           # 元素数据结构、项目元数据、工具类型与统一功能规则
├── ui/
│   ├── toolbar.ts     # 顶部工具栏（注册表驱动渲染 + 分组拆分按钮/下拉 + 填充开关 + 自定义布局与分组偏好）
│   ├── selectionbar.ts # 左侧选中悬浮栏（整理/手绘/裁剪/样式浮层 + 文字字号）
│   ├── statusbar.ts   # 右下状态栏（项目名 + 撤销/重做/缩放 + 元素信息）
│   ├── toolsfloat.ts  # 右侧圆形工具栏（文件/AI/清空/设置，可拖拽）
│   ├── exportdialog.ts # 统一导出弹窗（PNG / SVG 格式选择）
│   ├── settings.ts    # 设置弹窗（外观 / 工具栏 / AI 模型 / AI 工具 / 系统提示词 / 数据存储目录）
│   ├── contextmenu.ts # 右键菜单（复制/粘贴/锁定等操作）
│   └── style.css
└── board/
    ├── canvas.ts      # 画布核心：绘制/缩放/选择/橡皮擦/图片/剪贴板/样式应用/序列化/手绘风格转换/网格吸附与 SVG 导出
    ├── bounds.ts      # 元素包围盒计算（AI 感知 / 几何交互共用）
    ├── arrange.ts     # 排列纯函数：对齐 / 分布 / 翻转 / 层序（AI 的 arrange_elements 工具专用）
    ├── registry.ts    # 统一功能注册表：内置 + 自定义工具（AI 增删改，持久化适配器注入——桌面数据目录文件 / 浏览器 localStorage）
    ├── beautify.ts    # 整理：手绘形状识别与完善（圆/椭圆/矩形/多边形/直线）
    ├── coords.ts      # 元素局部 ↔ 画布绝对坐标换算（AI 上下文描述与 update_elements 写回共用）
    ├── offset.ts      # 粘贴平移纯函数（按元素坐标语义整体平移：line/arrow/path 平移 points/path，其余平移 x/y）
    ├── svg.ts         # SVG 导出纯函数（元素数据 → SVG 字符串，浏览器/桌面端共用）
    ├── stroke.ts      # 压力敏感笔迹封装（perfect-freehand：采样点 → 轮廓 path）
    ├── rough.ts       # 手绘风格渲染层（rough.js：标准图形 → 手绘 path，seed 可复现）
    └── history.ts     # 撤销重做
```

## 功能细节

- **绘图工具**：选择、画布移动、画笔、橡皮擦、直线、箭头、文本、框架等（工具栏由统一功能注册表驱动，AI 可运行时添加自定义工具）
  - **分组下拉**：同类型工具收纳进同一下拉按钮——“形状▾”（矩形 / 椭圆 / 三角形 / 五角星等形状类工具）、“选择▾”（选择 / 框选 / 套索）与“AI 工具▾”（AI 生成的其余自定义工具默认收纳，避免平铺顶栏）；分组按钮为拆分式——点击主按钮直接使用组内当前工具（“组头”，在菜单中任选一个即切换），点击右侧箭头展开菜单（菜单项右侧显示快捷键，AI 工具▾ 底部提供“管理 AI 工具”直达入口）；AI 创建的形状类新工具自动归入“形状▾”；自定义工具管理在 ⚙ 设置 →「AI 工具」页签
  - **自定义工具栏**（⚙ 设置 →「工具栏」页签）：平铺区与分组收纳区分开布局——平铺区（勾选顶栏 + 拖拽排序，AI 自定义工具标注 AI 徽章）、分组收纳区（分组头可拖拽调整分组在顶栏中的顺序，顶部工具栏同步）、隐藏区；拖拽落点按目标行上下半判定插入其前/后，工具行与分组按钮行可互相拖拽插入，拖到自动同步的分组按钮副本（虚线行）即固定其位置；勾选/排序实时预览顶栏效果（超出建议上限自动折叠进“更多▾”），自定义布局持久化到 localStorage；勾选后的工具按设定顺序平铺，未勾选的分组工具收纳进对应下拉、未勾选的独立工具隐藏；「恢复默认」一键还原初始布局
    - **自定义分组**：分组区右上角「＋ 新建分组」创建自定义分组（可重命名 / 删除），拖任意工具行到分组头上即归入该组（空分组也显示、可拖入；拖回内置组头恢复默认归属）；分组按钮组头 = 菜单中当前选中的工具，任选一个即切换；平铺区与分组区相互分离——分组头拖入平铺区即在落点插入完整分组按钮（组保持整体不拆开），分组按钮行拖回分组区即移除
  - 画笔为压力敏感笔迹（perfect-freehand）：实时生成平滑的变宽轮廓，笔迹粗细随速度/压力自然变化；选中笔迹可在样式浮层调整粗细（1–40，调整时按新粗细重算轮廓），画笔工具激活时左侧栏同样显示样式按钮，可预先设置新笔迹的默认颜色/粗细
  - 橡皮擦为分段擦除：擦除画笔笔迹与**直线/箭头**时只擦橡皮轨迹覆盖的区间，剩余部分自动拆成独立笔画/线段（线段拆分时首段保起点箭头、末段保终点箭头）；其余元素在圆心触及本体时整条删除（大半径蹭边不误删）；**待删预览**——悬停/拖动经过时红色虚线框实时指示将删除的目标；锁定元素受保护不可擦除
    - **橡皮半径可调**：橡皮激活时左侧栏显示半径滑条；`[` `]` 快捷键步进；橡皮模式下滚轮直接调节（不缩放画布）；半径跨启动记忆
    - **长按临时橡皮**：按住 `E` 借用橡皮擦除，松手自动回到原工具；快速单击 `E` 则持久切换（与旧版一致）
  - **方向键微移**：方向键移动选中元素 1px（按住连发）；`Shift+1` 缩放至全部内容、`Shift+2` 缩放到选中元素；双击空白处就地创建文本并进入编辑
  - **绘制后自动回选择工具**：绘制工具完成且实际生成元素后自动切回选择（Excalidraw 同款默认行为；⚙ 设置 →「外观」→ 绘制可关，点击落空不切换）
  - 快捷键：`V` 选择 / `H` 画布移动 / `M` 框选 / `Q` 套索 / `P` 画笔 / `E` 橡皮擦 / `L` 直线 / `A` 箭头 / `R` 矩形 / `O` 椭圆 / `T` 文本 / `F` 框架 / `K` AI 助手开关 / `Ctrl+K` 命令面板 / `Ctrl+B` 文字加粗；所有快捷键可在 ⚙ 设置 →「快捷键」页签自定义（操作 + 内置工具全部可改键，冲突自动检测提示，一键恢复默认）；AI 自定义工具可分配单字母快捷键（在「AI 工具」页签编辑）
- **AI 助手**（🤖 按钮或 `K` 键，OpenAI 兼容接口，支持流式输出）：
  - **交流模式**：通过 `get_canvas` 感知画布内容（结构化 JSON：整体摘要 + 元素数据，含图形形状描述、region 区域标签与画布绝对坐标，手绘笔迹同样给出识别形状，AI 创建的元素带 intent 字段——创建时自报的用途，不带 intent 的元素不猜测其用途；摘要含元素统计、内容范围与空间分布——内容集中在哪个区域、哪里空旷一目了然），对话 / 评价 / 给建议；把想法用 `draw_flowchart` 画成流程图写入画布（节点矩形与文字自动同组、连线箭头自动绑定节点，移动节点连线跟随）；明确要求“画 / 添加 / 放一个（些）元素”时用 `create_elements` 按 leafer 官方 JSON 格式直接创建（type 与 x/y 必填，line/arrow 的 points 用画布绝对坐标，无需 id，系统自动分配，可选 intent 简短自报创建意图并持久化保存）；批量整理元素（对齐 / 分布 / 翻转 / 层序）用 `arrange_elements` 一次调用完成（语义指令 + 前端计算坐标，同组成员整组参与，锁定元素自动跳过）；整理手绘笔迹用 `beautify_elements`、标准图形转手绘风格用 `sketchify_elements`、调整手绘粗糙度用 `set_roughness`（均按 id 操作，锁定元素自动跳过、同组成员整组参与）；不擅自改动画布，除非明确要求；同轮对话中画布未被修改时不重复调用 `get_canvas`（工具使用纪律，节省轮次与 token）
  - 长对话自动压缩：历史按 token 预算管理（约 8000，含系统提示词），超限自动丢弃最早轮次并提示一次；仅剩当前轮时把较早的画布数据收缩为占位说明（模型可随时重新 `get_canvas`），保证最近上下文完整
  - **生成控制**：生成中发送按钮变为红色“停止”，点击立即中断（已输出的内容保留，可继续对话）；对话请求 90 秒无响应自动停止，连接测试 / 模型列表探测 15 秒超时，不会无限挂起
  - **编辑模式**：按统一功能规则运行时添加 / 修改 / 删除绘制工具（AI 生成代码函数，立即生效并持久化——桌面端存数据目录 custom-tools.json，浏览器端存 localStorage）；工具行为分两类——**drag 拖拽生成**（根据拖拽范围动态计算形状，默认）与 **click 点击生成**（点击即生成固定大小元素，如印章 / 便利贴）；生成器可返回单个元素或元素数组（**组合工具**，如标题 + 下划线，拖拽中其余元素与主草稿实时同步预览，松手合并为一步撤销）；添加 / 修改前自动**冒烟测试**（危险代码扫描 → 隔离 Worker 执行 + 超时熔断 → 返回值格式强校验，未通过返回具体原因供 AI 修正重试），验证通过后自动在画布右侧**试画示例**供立即查看；创建与已有工具同类型的新工具时归入同一分组下拉；功能区操作在面板中显示工具卡片回执（图标 + 名称 + 行为类别 / 分组 / 快捷键徽章）；工具图标受字符白名单校验（1-2 个字符的中文 / 字母 / 数字 / 常见符号，拒绝 emoji 与超长符号，旧数据自动回退为默认符号）
  - **清除对话**：面板头部垃圾桶按钮一键清空当前对话记录（不影响画布内容），切换模式时自动清空
  - **AI 工具管理**：⚙ 设置 →「AI 工具」页签——编辑名称 / 图标 / 快捷键 / 分组与**生成器源码**（源码修改保存前自动过冒烟测试，未通过不落盘）、删除工具；**导入 / 导出**——导出为 custom-tools.json 开放格式，导入逐个强制过冒烟测试（未通过 / 快捷键冲突的逐一说明并跳过）；**使用统计**——实际完成绘制才计数（×N 徽标），支持 最常用 / 最近使用 / 按名称 排序与「清理未使用」（应用内确认后一键删除从未用过的工具）

## FAQ

**Q：AI 助手连不上？**
A：先在 ⚙ 设置 → AI 模型 页签点「测试连接」。常见原因：接口地址不是 `/v1` 结尾、Key 错误、模型名不存在。本地 Ollama 用 `http://localhost:11434/v1`。

**Q：数据存在哪里？怎么备份？**
A：见上方 [数据存储](#-数据存储) 章节。默认 `%APPDATA%\com.miniboard.app\`，关闭应用后复制该目录即可完整备份。

**Q：更改数据目录后原来的数据还在吗？**
A：在。更改目录时旧数据会自动复制到新目录（迁移期间请勿关闭应用），原目录文件保留，确认无误后可手动删除。

**Q：浏览器调试和桌面版数据互通吗？**
A：不互通。浏览器版数据存 localStorage，桌面版存文件目录，两者相互独立。

**Q：AI 生成的工具会破坏画布吗？**
A：不会。工具生成器经过三层防护：危险代码静态扫描 → 隔离 Worker 执行 + 超时熔断 → 返回值格式强校验，且只允许纯 JavaScript 数学计算（不能访问页面 / 网络 / 循环）。
