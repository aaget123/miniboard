# Miniboard 白板

本地优先的手绘白板应用。桌面端由 Tauri 2 承载，画布使用 leafer-ui 2.2.9 渲染，支持在浏览器中调试运行（功能与桌面端一致）。

## 功能

- **绘图工具**：选择、画布移动、画笔、橡皮擦、直线、箭头、文本等（工具栏由统一功能注册表驱动，AI 可运行时添加自定义工具）
  - **分组下拉**：同类型工具收纳进同一下拉按钮——“形状▾”（矩形 / 椭圆 / 三角形 / 五角星等形状类工具）与“选择▾”（框选 / 套索）；AI 创建的形状类新工具自动归入“形状▾”
  - 画笔为压力敏感笔迹（perfect-freehand）：实时生成平滑的变宽轮廓，笔迹粗细随速度/压力自然变化
  - 快捷键：`V` 选择 / `H` 画布移动 / `M` 框选 / `Q` 套索 / `P` 画笔 / `E` 橡皮擦 / `L` 直线 / `A` 箭头 / `R` 矩形 / `O` 椭圆 / `T` 文本 / `K` AI 助手开关
- **AI 助手**（🤖 按钮或 `K` 键，OpenAI 兼容接口，支持流式输出）：
  - **交流模式**：通过 `get_canvas` 感知画布内容（结构化 JSON：整体摘要 + 元素数据，含图形形状描述与画布绝对坐标，手绘笔迹同样给出识别形状），对话 / 评价 / 给建议；把想法用 `draw_flowchart` 画成流程图写入画布；明确要求“画 / 添加 / 放一个（些）元素”时用 `create_elements` 按 leafer 官方 JSON 格式直接创建（type 与 x/y 必填，line/arrow 的 points 用画布绝对坐标，无需 id，系统自动分配）；不擅自改动画布，除非明确要求
  - 长对话自动压缩：历史按 token 预算管理（约 8000，含系统提示词），超限自动丢弃最早轮次并提示一次；仅剩当前轮时把较早的画布数据收缩为占位说明（模型可随时重新 `get_canvas`），保证最近上下文完整
  - **生成控制**：生成中发送按钮变为红色“停止”，点击立即中断（已输出的内容保留，可继续对话）；对话请求 90 秒无响应自动停止，连接测试 / 模型列表探测 15 秒超时，不会无限挂起
  - **编辑模式**：按统一功能规则运行时添加 / 修改 / 删除绘制工具（AI 生成代码函数，立即生效并持久化 localStorage）；创建与已有工具同类型的新工具时归入同一分组下拉
  - **@ 选区**：选中图形后点面板 @ 按钮，AI 将重点分析这些元素（选区数据与用户消息合并为一条注入，不截断）；明确要求时用 `update_elements` 直接优化（改颜色 / 尺寸 / 位置 / 文字 / 端点等），整轮改动合并为一步撤销，且只改 @ 选区内元素；写入受字段白名单保护（仅外观 / 几何字段，运行时字段一律忽略）
  - **设置**（☰ 文件与工具 → ⚙）：项目（见下）+ 主题切换（深色 / 浅色，画布背景与导出同步）+ 画布网格（见下）+ AI 模型配置管理——可注册多个配置（名称 / 接口地址 / API Key / 模型名 / 多模态，localStorage 保存），点选激活使用，支持编辑、删除与一键测试连接（自动拉取可用模型列表点选，/models 不可用时降级为最小请求验证）；多模态开启后交流模式随消息附带画布截图
- **选择**：像素级命中（线段/箭头/画笔按实际描边命中）；细线带 5px 命中容差；空心图形透明区域可穿透选中下层元素
  - **框选 / 套索**：收纳在“选择▾”分组下拉中——框选为矩形选框选中相交元素，套索为自由圈选闭合区域
  - **选中框内拖动**：在选中元素包围盒内的空白区域按下拖动，可整体移动单个或多个选中元素（悬停显示移动光标）
  - **选中栏按类型差异化**：左侧选中悬浮栏随元素类型显示对应按钮——图片显示 ✂️ 裁剪、直线/箭头显示点编辑、文本显示字号滑块；切换到非选择工具或文本编辑中自动隐藏，显隐带过渡动画
- **样式编辑**：选中元素后可直接修改描边颜色 / 填充颜色 / 描边粗细 / 文字字号（选中文字时样式浮层额外显示字号滑块 10–72，拖动即时改大小）
  - 描边与填充双通道独立：点击“描边”/“填充”按钮切换激活通道，色板与自定义取色器作用于当前通道（填充 = 所选色 15% 半透明，填充通道点击自动开启填充）
  - 填充开关（顶部工具栏图标按钮：方块 + 下半实心）：开 = 用记忆的填充色填充，关 = 移除填充；锁定元素与图片不受影响；Path 闭合形状（含 AI 生成的三角形/五角星）同样支持填充
  - Text 元素：两通道均作用于文字颜色
- **图片插入**：右侧圆形工具栏 🖼️ 按钮选择本地图片插入，插入后自动选中，可移动 / 缩放 / 旋转（大图自动缩至视口内）
  - **图片裁剪**：选中图片后点选中栏 ✂️ 按钮进入裁剪模式，拖动裁剪框边 / 角手柄调整范围，双击应用（仅支持未旋转图片）
- **文本编辑**：文本工具点击画布 → 创建空文本并就地编辑（透明覆盖层 WYSIWYG：输入实时显示在画布上，字号 / 颜色 / 缩放同步跟随）；双击已有文本再次编辑
  - 编辑框自动聚焦，点击即可直接输入；`Esc` 退出编辑；内容有变化才记入撤销历史，空文本自动删除不留痕
  - **缩放语义**：选中文本后拖拽缩放手柄——横向缩放自动换行（字号不变），纵向缩放直接改字号，不会拉伸变形
- **右键菜单**：复制 / 粘贴 / 剪切 / 删除 / 全选 / 置顶 / 置底 / 锁定 / 解锁（锁定后元素不可移动、缩放、删除）
  - 快捷键：`Ctrl+C` 复制 / `Ctrl+X` 剪切 / `Ctrl+V` 粘贴 / `Ctrl+A` 全选；粘贴时新元素跟随鼠标当前位置（以复制内容包围盒中心对齐）
- **整理**（左侧选中悬浮栏 ✨ 按钮）：智能识别手绘形状并完善为标准图形——闭合路径按形状识别为圆 / 椭圆 / 矩形（支持旋转）/ 三角形 / 四边形 / 五边形等标准元素，近似直线转为标准线段，其余弯曲线条做拉直简化（Douglas-Peucker，容差 5px）；保留颜色与粗细，可继续拖动调整（画笔笔迹以原始采样点为识别源，识别为椭圆/直线后可直接编辑）
- **手绘风格**（左侧选中悬浮栏 ✎ 按钮）：选中标准图形（矩形 / 椭圆 / 直线 / 箭头 / 多边形）一键转为 rough.js 手绘外观（双线 + 抖动描边），抖动 seed 随元素保存、撤销重载后完全可复现；AI 感知时能识别出原始几何形状；对已手绘元素重复点击自动跳过
- **线性元素点编辑**：选中直线 / 箭头 / 多边形后显示可拖拽的点手柄，拖动端点实时改变形状；双击线段中部添加新顶点；支持闭合路径 / 锁定角度（`Esc` 或切换工具退出）
- **箭头端点绑定**：箭头端点靠近其他元素边缘时自动吸附绑定，拖动被绑定元素时箭头端点跟随移动，绑定关系随文件保存恢复
- **画布网格**（⚙ 设置）：可开启网格显示与绘制 / 移动吸附，间距 4–100px 可调（默认关闭）；开启吸附后新建图形、框内拖动与单选移动均对齐网格线（多选移动不吸附，保持相对位置），网格线随缩放 / 平移自动重建
- **画布缩放**：自由缩放 10% ~ 800%
  - 滚轮：以鼠标所在位置为中心，向上放大 / 向下缩小
  - 状态栏按钮：`−` 缩小 / `100%` 还原 / `＋` 放大（还原同时复位画布平移）
  - 快捷键：`Ctrl+=` 放大、`Ctrl+-` 缩小、`Ctrl+0` 还原
  - 状态栏实时显示当前百分比
- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`）；右下状态栏提供 ⬅ / ➡ 按钮
- **多项目管理**（⚙ 设置 → 项目）：可创建 / 切换 / 重命名 / 删除多个项目，每个项目独立画布与自动保存；启动自动恢复上次打开的项目，旧版单项目数据自动迁移为「项目一」；状态栏左侧显示当前项目名
- **存储**：自动保存到当前项目（桌面端写入系统应用数据目录，浏览器端写入 localStorage）；打开 / 另存为 JSON 文件；导出 PNG 图片、导出 SVG 矢量图（元素结构无损，适合交付 / 打印 / 二次编辑）

## 界面布局

Excalidraw 同款布局，多区域悬浮控件互不遮挡：

- **顶部中央工具栏**（常驻）：全部绘图工具（含“形状▾”/“选择▾”分组下拉）+ 填充开关（纯图标，与其他按钮对齐）
- **左侧选中悬浮栏**（选中元素时出现）：✨ 整理 / ✎ 手绘 / 🎨 样式（描边/填充双通道色板、取色器、粗细滑块；按钮随元素类型差异化——图片 ✂️ 裁剪、线性元素点编辑、选中文字时额外显示字号滑块）
- **右侧圆形悬浮工具栏**（常驻）：📂 打开 / 💾 保存 / 🖼️ 插入图片 / 📷 导出 PNG / 📄 导出 SVG / 🤖 AI 助手 / 🗑 清空 / ⚙ 设置（项目 + 主题 + 画布网格 + AI 模型配置）；主按钮可拖拽移动（位置记忆在 localStorage，恢复与窗口缩放时自动夹回视口内）；鼠标移开延迟收起防误收；AI 面板打开时自动淡出让位
- **右下角状态栏**（半透明底栏）：当前项目名 + 元素数 + 光标画布坐标，右侧 ⬅ 撤销 / ➡ 重做 / 🔍 − 100% ＋
- **悬浮内容互斥**：右键菜单 / 样式浮层 / 右侧面板互斥，打开其一自动收起其他；`Esc` 逐层退出（点编辑 → 图片裁剪 → 编辑框 → 浮层），点击空白处或失焦关闭浮层

## 技术栈

| 层 | 技术 |
| --- | --- |
| 桌面壳 | Tauri 2（Rust） |
| 前端构建 | Vite 6 + TypeScript |
| 画布渲染 | leafer-ui 2.2.9 + @leafer-in/editor / arrow / export / text-editor |
| 笔迹轮廓 | perfect-freehand（压力敏感笔迹平滑与轮廓生成） |
| 手绘外观 | roughjs（标准图形 → 手绘风格路径，seed 可复现） |
| AI 助手 | OpenAI 兼容接口（SSE 流式）：浏览器直接 fetch，桌面端经 @tauri-apps/plugin-http 转发 |

## 开发调试

开发阶段推荐直接在浏览器中调试，不需要构建 exe：

```bash
npm install
npm run dev        # 浏览器打开 http://localhost:5173
```

需要验证桌面集成（文件对话框、系统存储等）时再运行桌面开发模式：

```bash
npm run tauri dev
```

核心纯函数模块（坐标换算 / 形状识别）带单元测试：

```bash
npm test
```

## 构建

仅在功能调试完成、需要交付 exe 时执行：

```bash
# Windows（自动注入 MSVC 环境）
powershell -ExecutionPolicy Bypass -File tools/build-tauri.ps1

# 或 Tauri 官方命令
npm run tauri build
```

产物位置：`src-tauri/target/release/`（exe 与 NSIS 安装包）；`release/` 目录为本地留存的便携 exe 副本（不提交到仓库）。

## 项目结构

```
src/
├── ai/               # AI 助手：双模式对话 / 工具调用 / 设置 / @ 选区
│   ├── panel.ts      # AI 面板（交流/编辑双模式、@ 选区、上下文压缩、停止/超时）
│   ├── client.ts     # OpenAI 兼容客户端（SSE 流式 / 超时与取消 / 模型列表 / 连接测试）
│   ├── config.ts     # AI 多配置存储（localStorage，旧版单配置自动迁移）
│   ├── prompts.ts    # 双模式系统提示词
│   ├── tools.ts      # 画布感知 / 形状识别 / 工具执行器（update_elements 字段白名单、create_elements 官方格式解析）
│   └── types.ts
├── main.ts            # 入口：工具栏/状态栏/快捷键/右键菜单接线
├── storage.ts         # 存储层：多项目管理（项目索引 + 独立场景 + 旧数据迁移）/ 打开 / 另存 / 导出 PNG 与 SVG
├── types.ts           # 元素数据结构、项目元数据、工具类型与统一功能规则
├── ui/
│   ├── toolbar.ts     # 顶部工具栏（注册表驱动渲染 + 形状/选择分组下拉 + 填充开关）
│   ├── selectionbar.ts # 左侧选中悬浮栏（整理/手绘/样式浮层 + 文字字号）
│   ├── statusbar.ts   # 右下状态栏（项目名 + 撤销/重做/缩放 + 元素信息）
│   ├── toolsfloat.ts  # 右侧圆形工具栏（文件/AI/清空/设置，可拖拽）
│   ├── settings.ts    # 设置弹窗（项目 / 主题 / 画布网格 + AI 多配置管理）
│   ├── contextmenu.ts # 右键菜单（复制/粘贴/锁定等操作）
│   └── style.css
└── board/
    ├── canvas.ts      # 画布核心：绘制/缩放/选择/橡皮擦/图片/剪贴板/样式应用/序列化/手绘风格转换/网格吸附与 SVG 导出
    ├── registry.ts    # 统一功能注册表：内置 + 自定义工具（AI 增删改，localStorage 持久化）
    ├── beautify.ts    # 整理：手绘形状识别与完善（圆/椭圆/矩形/多边形/直线）
    ├── coords.ts      # 元素局部 ↔ 画布绝对坐标换算（AI 上下文描述与 update_elements 写回共用）
    ├── svg.ts         # SVG 导出纯函数（元素数据 → SVG 字符串，浏览器/桌面端共用）
    ├── stroke.ts      # 压力敏感笔迹封装（perfect-freehand：采样点 → 轮廓 path）
    ├── rough.ts       # 手绘风格渲染层（rough.js：标准图形 → 手绘 path，seed 可复现）
    ├── history.ts     # 撤销重做
```

核心纯函数模块（坐标换算 / 形状识别）配 `*.test.ts` 单元测试，`npm test` 运行。
